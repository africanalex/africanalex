## Alexander Baxter

**Senior Java / Kotlin engineer: banking and payments integration, and AI agent infrastructure.**

I build the software that sits between banks, payment switches and the people using them. More recently, I also build the tooling that lets AI coding agents do real work safely.

### What I work on

- **Banking & payments integration:** Spring services connecting digital channels to Postilion (ISO 8583) and Temenos T24 (SOAP); an SMPP gateway that sent 1.2M messages in a day; idempotent account-opening workflows; payment terminal (Ingenico) prototypes.
- **Fintech apps:** an offline-first Android invoicing app with mutual-TLS tax fiscalisation and hash-chained receipt signing (Kotlin, Room, Supabase).
- **AI agent infrastructure:** an orchestration system that dispatches tasks to Claude Code agents on a schedule, keeps their progress in Markdown and YAML front matter instead of long sessions, and gives agents no credentials, so anything that needs a secret goes through a human approval queue.
- **Safe AI for NGOs:** a retrieval-based support tool for gender-based violence survivors with deterministic safety routing and PII redaction (Amazon Bedrock, Cloudflare Workers).
